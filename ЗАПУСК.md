# Как запустить платформу у себя

## Способ 1 — в один клик

Дважды щёлкните файл **`start.cmd`** в этой папке.

Скрипт сам проверит Node.js, при первом запуске установит зависимости
(это займёт несколько минут), поднимет сервер и откроет браузер
на адресе **http://localhost:4321**.

Чтобы остановить — закройте чёрное окно или нажмите `Ctrl+C`.

> **Почему порт 4321, а не привычный 3000.** На этом компьютере порты 3000 и 3001
> уже заняты другими вашими проектами — платформа специально живёт на отдельном
> порту, чтобы не мешать им и не путаться, какое приложение открыто.

## Способ 2 — вручную в терминале

Откройте PowerShell в этой папке и выполните:

```powershell
npm install     # только при первом запуске
npm run dev     # запуск платформы
```

Затем откройте http://localhost:4321

## Что нужно установить один раз

**Node.js версии 20 или новее** — https://nodejs.org (кнопка LTS).

Проверить, что он есть:

```powershell
node -v
```

Если команда отвечает версией — всё готово, больше ничего ставить не нужно.
Docker, PostgreSQL и другие базы для запуска **не требуются**: платформа сейчас
работает на демонстрационных данных, которые лежат прямо в проекте.

## Что посмотреть внутри

Все адреса — с портом **4321**:

| Раздел | Адрес |
| --- | --- |
| Витрина программ | http://localhost:4321 |
| Страница программы (расписание, материалы, итоги) | http://localhost:4321/programs/obrazovanie-na-vysote |
| Рабочее пространство программы — канал | http://localhost:4321/programs/kinopedagogika/hub |
| Чаты: группы и личные диалоги | http://localhost:4321/programs/kinopedagogika/hub?tab=chats |
| Участники программы | http://localhost:4321/programs/kinopedagogika/hub?tab=members |
| Опросы и квизы | http://localhost:4321/programs/kinopedagogika/hub?tab=polls |

В правом верхнем углу хаба есть переключатель **«Смотреть как»** —
администратор, модератор или участник. Права действительно разные:
модератор публикует посты и закрепляет их, участник только комментирует
и отвечает в опросах. Так можно проверить оба сценария.

Хабы есть у всех семи демонстрационных программ: подставьте в адрес любой
другой slug, например `ai-urok` или `vesna-uchiteley`.

## Если порт 4321 тоже занят

```powershell
npm run dev -- -p 4400
```

и откройте http://localhost:4400

## Полезные команды

```powershell
npm run dev         # запуск с автоматической перезагрузкой
npm run build       # production-сборка вместе с проверкой типов
npm run start       # запуск собранной версии
npm run smoke       # автопроверка разделов в браузере (нужен запущенный сервер)
npm run shots       # пересобрать скриншоты в docs/screenshots
```

## Что сейчас на демонстрационных данных

Витрина, страницы программ, канал, чаты, участники и опросы наполнены
демонстрационным содержимым — оно лежит в `src/lib/mock/`. Программа
«Образование на высоте» заполнена реальными данными вашего одностраничника,
включая расписание по дням и ссылки на материалы.

Устройство такое: **если задана переменная `DATABASE_URL` — платформа читает
данные из PostgreSQL, если нет — из демонстрационного набора.** Поэтому запуск
у вас работает без базы, а на сервере база включается одной строкой.

## Как включить настоящую базу (необязательно)

У вас уже установлен PostgreSQL 18, база проекта создана. Чтобы платформа
читала данные из неё:

1. Скопируйте `.env.example` в `.env.local` и раскомментируйте строку:

   ```
   DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/mashuk_platform
   ```

2. Выполните один раз:

   ```powershell
   npm run db:migrate   # создать таблицы
   npm run db:seed      # перенести демонстрационные данные
   ```

3. Перезапустите `npm run dev`.

Дальше при изменении схемы:

```powershell
npm run db:generate  # сгенерировать миграцию по изменениям схемы
npm run db:migrate   # применить её
```

Чтобы вернуться к демонстрационным данным — удалите `.env.local`
или закомментируйте строку с `DATABASE_URL`.

## Как проверить вход по приглашению

После того как база подключена и наполнена (`npm run db:seed`), для каждого
участника создано приглашение. Два способа войти:

**Персональная ссылка** — откройте, например:

```
http://localhost:4321/invite/inv-u-mod-1        # Ирина Дорохова, модератор
http://localhost:4321/invite/inv-u-p-01         # Мария Ковалёва, участница
```

Ссылка одноразовая: сразу открывается хаб программы, роль берётся из базы.

**Код на почту** — на странице http://localhost:4321/join введите адрес
из демонстрационного списка (например `u-p-01@demo.mashuk`), нажмите
«Получить код».

В режиме разработки (`npm run dev`) код показывается прямо на экране.
В production-сборке он не показывается — почтовый и SMS-провайдеры
подключаются отдельно.

После входа в правом верхнем углу хаба видно, кто вошёл и с какой ролью:
модератор публикует посты и закрепляет их, участник только комментирует
и отвечает в опросах. Кнопка «Выйти» завершает сессию.

> Если проверяете **production-сборку** (`npm run build` + `npm run start`)
> по адресу `http://localhost:4321`, добавьте в `.env.local` строку
> `ALLOW_INSECURE_COOKIES=1` — иначе cookie сессии не отправится по http.
> В рабочей версии на сервере с HTTPS этого делать не нужно.
