# Как запустить платформу у себя

## Способ 1 — в один клик

Дважды щёлкните файл **`start.cmd`** в этой папке.

Скрипт сам проверит Node.js, при первом запуске установит зависимости
(это займёт несколько минут), поднимет сервер и откроет браузер
на адресе **http://localhost:4321**.

Чтобы остановить — закройте чёрное окно или нажмите `Ctrl+C`.

> **Почему порт 4321, а не привычный 3000.** На этом компьютере порты 3000 и 3001
> уже заняты другими вашими проектами — платформа специально живёт на отдельном
> порту, чтобы не мешать им и не путаться, какое приложение открыто.

## Способ 2 — вручную в терминале

Откройте PowerShell в этой папке и выполните:

```powershell
npm install     # только при первом запуске
npm run dev     # запуск платформы
```

Затем откройте http://localhost:4321

## Что нужно установить один раз

**Node.js версии 20 или новее** — https://nodejs.org (кнопка LTS).

Проверить, что он есть:

```powershell
node -v
```

Если команда отвечает версией — всё готово.

## Без базы и с базой

- **Без базы** открывается только витрина и страница программы — на
  демонстрационных данных из `src/lib/mock/`.
- **С базой** работает всё: вход по паролю, рабочее пространство (канал, чаты,
  опросы, расписание, сборка) и админка.

PostgreSQL 18 у вас уже установлен. Для проверки создана отдельная база
`mashuk_platform_v2`, и файл `.env.local` уже указывает на неё:

```
DATABASE_URL=postgres://postgres@127.0.0.1:5432/mashuk_platform_v2
```

Чтобы работать со своей прежней базой `mashuk_platform`, поменяйте имя базы
в `.env.local` и выполните `npm run db:migrate` — миграции перенесут контакты
участников и создадут общий чат, данные сохранятся.

## Первый запуск с базой

```powershell
npm run db:migrate   # создать или обновить таблицы
npm run db:seed      # ВНИМАНИЕ: очищает базу и заполняет программу «Образование на высоте»
npm run dev
```

Seed создаёт администратора Центра, пароль программы и демо-участников.
Логины и пароли лежат в **`storage/seed-credentials.txt`** (в git не попадает).
Свои пароли можно задать заранее: `SEED_ADMIN_PASSWORD`, `SEED_PROGRAM_PASSWORD`,
`SEED_DEMO_PASSWORD` в `.env.local`.

## Что посмотреть внутри

Все адреса — с портом **4321**:

| Раздел | Адрес |
| --- | --- |
| Витрина | http://localhost:4321 |
| Страница программы | http://localhost:4321/programs/obrazovanie-na-vysote |
| Вход в программу по паролю программы | http://localhost:4321/programs/obrazovanie-na-vysote/enter |
| Личный вход (логин и пароль) | http://localhost:4321/join |
| Рабочее пространство | http://localhost:4321/programs/obrazovanie-na-vysote/hub |
| Чаты | …/hub?tab=chats |
| Опросы и квизы | …/hub?tab=polls |
| Расписание | …/hub?tab=schedule |
| Сборка программы | …/hub?tab=build |
| Админка | http://localhost:4321/admin |

### Как попасть в программу

1. **Новый участник:** страница «Вход в программу» → «Я впервые» → пароль программы,
   имя, почта или телефон и свой пароль. Человек сразу попадает в общий чат.
2. **Уже участник:** почта или телефон и личный пароль — на `/join` или во вкладке
   «Я уже участник».
3. **Заранее заведённый участник:** администратор добавляет человека в админке
   и передаёт ему выданный пароль.

### Админка

Вход администратором Центра → `/admin`. Для каждой программы:

- **Основное** — название, даты, место, описание, ссылки;
- **Расписание** — дни и события по времени;
- **Материалы** — ссылки по дням;
- **Доступ и участники** — пароль программы, состав, роли, новые пароли;
- **Сборка** — загрузка вашей HTML-папки (`index.html` + файлы); участники
  открывают её во вкладке «Сборка программы».

Модератор видит в админке только свои программы и управляет участниками,
но не командой. Опросы ведущий запускает в рабочем пространстве: вкладка
«Опросы и квизы» → «Создать опрос» → «Запустить» → «Открыть приём».

## Если порт 4321 тоже занят

```powershell
npm run dev -- -p 4400
```

и откройте http://localhost:4400

## Полезные команды

```powershell
npm run dev            # запуск с автоматической перезагрузкой
npm run build          # production-сборка
npm run start          # запуск собранной версии
npm run typecheck      # проверка типов
npm run smoke          # сквозная проверка в браузере (нужны сервер и seed)
npm run shots          # скриншоты в docs/screenshots
npm run audit:design   # аудит дизайна: токены, фокус, контраст
npm run admin:create -- admin@mashuk.ru "Имя Фамилия"   # администратор Центра без очистки базы
npm run db:generate    # миграция по изменениям схемы
npm run db:migrate     # применить миграции
```

> Если проверяете **production-сборку** (`npm run build` + `npm run start`)
> по адресу `http://localhost:4321`, добавьте в `.env.local` строку
> `ALLOW_INSECURE_COOKIES=1` — иначе cookie сессии не отправится по http.
> В рабочей версии на сервере с HTTPS этого делать не нужно.
