# Аудит дизайна

Цель — найти расхождения с фирменным стилем и проблемы доступности дёшево и воспроизводимо: сначала скрипт, потом точечное чтение, скриншоты — в последнюю очередь.

## Источники правды (не читать PDF и `../guideline_text.txt` целиком)
- Токены: `src/app/globals.css` (блок `@theme`, `:root`, `[data-season]`) и `src/lib/brand.ts`.
- Правила брендбука в сжатом виде: [references/brand-rules.md](references/brand-rules.md).
- Только если выжимки не хватает — `Grep` по `../guideline_text.txt` с узким шаблоном.

## Порядок
1. **Автопроверка**: `npm run audit:design` (или `node scripts/design-audit.mjs`). Выдаёт по правилам `файл:строка — находка` и таблицу контраста пар токенов. `--all` — полный список; без нужды не запускать.
2. **Разбор находок** — читать только указанные строки (`Read` с `offset`/`limit` ≈ 20 строк вокруг). Ложные срабатывания отметить и не чинить:
   - hex в `Avatar.tsx` (палитра аватаров) — допустимо, если все цвета из брендбука;
   - `export.ts` — рисование на canvas, токены CSS там недоступны.
3. **Визуальная проверка** (только если просили или код-аудит не отвечает на вопрос):
   - `npm run shots` при запущенном `npm run dev` → `docs/screenshots/*.png` (1440px). Смотреть 2–3 ключевых снимка, не все.
   - Мобильная ширина: встроенный браузер, `resize_window` preset `mobile`, `get_page_text`/`read_page` для структуры, скриншот с `scale: 0.5`. Не забыть вернуть `desktop`.
   - Сезоны: на странице программы акцент берётся из `data-season` — проверить хотя бы лето (самый низкий контраст белого на акценте).
4. **Отчёт** — по разделам, от критичного к косметике, каждая находка со ссылкой `файл:строка` и конкретным исправлением (какой токен подставить):
   - Критичное (сломанная вёрстка, нечитаемый текст, недоступные элементы);
   - Брендбук (цвета вне палитры, шрифты, логотип, линейные градиенты);
   - Доступность (контраст, фокус, alt, aria-label);
   - Адаптив;
   - Системность (повторяющиеся произвольные значения → кандидаты в токены).

## Что считать нарушением
- Цвет вне палитры или хардкод цвета из палитры вместо токена (`text-[#223F9A]` → `text-navy`).
- Белый текст на акцентной заливке (`bg-accent`, `background: var(--accent)`): во всех сезонах ниже 4,5:1. Правильно — `text-on-accent`; акцент как текст на светлом — `text-accent-ink`; золото как текст — `text-gold-ink`.
- Новый цветовой токен, зависящий от сезона, объявлять в `@theme inline` — иначе Tailwind вычислит его на `:root`, и все программы получат акцент по умолчанию.
- `outline-none` без `focus-visible:` стиля в том же `className`.
- Произвольные размеры `text-[13px]`, `rounded-[14px]`, `p-[18px]` — заменить на шкалу (`text-meta`, `rounded-field`, `p-4.5`); шкала описана в `@theme` в `globals.css`.
- Шрифты, кроме Geologica (UI, заголовки) и Noto Serif (длинные тексты, `font-long`); Verdana — только fallback.
- Линейные градиенты в декоре — брендбук рекомендует mesh/радиальные.

## Правки
Аудит по умолчанию только отчитывается. Исправлять — если пользователь попросил; после правок: `npm run audit:design` (счётчики должны уменьшиться) и `npm run typecheck`.
