# Брендбук «Машук» — выжимка для аудита

Источник: «Руководство по использованию фирменного стиля», 41 стр. (`../Guidline Mashuk.pdf`, текст — `../guideline_text.txt`). Номера страниц — по руководству.

## Цвета (стр. 10–14)
Основные (общие для всех сезонов): navy `#223F9A`, grey `#DCDEDD`, ink `#332D24`.
Дополнительные (общие): sky `#54A4DB`, чёрный `#0A1014`, paper `#FAFAFA`, gold `#A2855F`.
Правило: **один основной цвет сочетается с дополнительными**.

| Сезон | Основной сезонный | Дополнительный сезонный |
|---|---|---|
| Весна | `#0B4D4D` (teal) | `#3AD754` |
| Лето | `#FF5B00` | `#F18300` |
| Осень | `#F24559` | `#F68E9A` |
| Зима | `#4582F2` | `#D6E3FB` |

В коде: `--color-*` в `@theme`, акцент программы — `--accent`/`--accent-strong` через `[data-season]`.
Производные оттенки (`navy-deep`, `navy-soft`, `sky-*`, `ink-soft/muted/faint`, `paper-warm`) — допустимы, это тона палитры для интерфейса.

## Градиенты (стр. 15–16)
- Не рекомендуются линейные градиенты; предпочтение — mesh-градиентам с плавными переходами.
- Цвета одной палитры, без резких границ, текст должен оставаться читаемым.

## Типографика (стр. 22–24)
- Основной шрифт — **Geologica**: заголовок Bold/SemiBold, подзаголовок Medium, основной текст Regular/Light, функциональные сообщения Light Italic.
- Основной текст — увеличенный межстрочный интервал; заголовки — плотнее.
- **Noto Serif** — только для длинных методических/аналитических текстов; заголовки всё равно Geologica.
- **Verdana** — только fallback, когда Geologica недоступна.

## Логотип (стр. 3–9)
- Пропорции и интервалы фиксированы — не растягивать, не перекрашивать вне цветовых версий.
- Версии: основная (сайт, презентации), упрощённая (интерфейс, малый формат), иконка (аватар, элементы интерфейса), английская.
- Охранное поле: внутри — никаких элементов, текста, изображений. Минимальные размеры: 28 / 20 / 10 мм для основной / упрощённой / иконки.
- Фон: однотонный светлый или фирменный; на фото — инверсия или подложка.
- Файлы: `public/brand/logo/*` (есть сезонные варианты `seasonal/`).

## Иконки и элементы (стр. 17–19)
- Фирменные иконки: сохранять пропорции, фирменные цвета, не менять толщину линии, без эффектов (теней, свечения).
- Новые иконки — простая геометрия, единая толщина линий, минимум деталей (`lucide-react` с одинаковым `strokeWidth` — допустимо).
- Контурные геометрические фигуры — для композиции.

## Текст и маскот (стр. 19–21)
- Слоган «Знания на высоте», миссия «Учим тех, кто учит».
- Маскот «Машутка» (лиса) — дополнительный элемент, **не заменяет логотип**.

## Фото (стр. 25)
Лаконично, естественное освещение, нейтральная цветокоррекция, в палитре бренда.
