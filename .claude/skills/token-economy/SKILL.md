# Экономия токенов

Главные расходы в этом проекте: чтение больших файлов целиком, широкие обходы каталогов, скриншоты и повторное чтение одного и того же. Ниже — что делать вместо этого.

## Никогда не читать (заблокировано в `.claude/settings*.json`)
| Путь | Почему | Что вместо |
|---|---|---|
| `../_*.txt`, `../_research/**` | выгрузки нормативных актов, до 1 МБ | `Grep` с узким шаблоном и `head_limit` |
| `../*.pdf`, `../.brand/**`, `../Documents/**` | брендбук и картинки страниц | `design-audit/references/brand-rules.md` |
| `pnpm-lock.yaml`, `drizzle/meta/*.json` | машинные файлы | `package.json`, `src/lib/db/schema.ts` |
| `public/uploads/**`, шрифты | бинарные | — |

`docs/screenshots/*.png` не заблокированы, но каждый снимок дорогой: смотреть 1–2 нужных, а не все.

## Большие файлы — только кусками
`src/lib/mock/programs.ts` (~900 строк), `mock/chat.ts`, `mock/polls.ts`, `mock/hub.ts`, `PollsView.tsx`, `PollBuilder.tsx`, `HubApp.tsx`, `queries.ts`, `globals.css` (~480).
Сначала `Grep -n` по нужному символу → затем `Read` с `offset`/`limit` (30–60 строк).

## Приёмы
1. **Карта есть в `CLAUDE.md`** — не обходить дерево каталогов заново.
2. **Поиск**: `Grep` (`output_mode: files_with_matches` → потом `content` с `-C 3` и `head_limit`) вместо открытия файлов подряд. `Glob` вместо `ls -R`/`find`.
3. **Не перечитывать** файл после `Edit`/`Write` — инструмент сам сообщит об ошибке.
4. **Скрипты вместо ручного анализа**: `npm run audit:design`, `npm run typecheck`, `npm run build` — их вывод короче, чем разбор кода глазами. Длинный вывод обрезать (`| tail -40`, `| grep error`).
5. **Браузер**: `get_page_text`/`read_page` с `filter: "interactive"` вместо скриншотов; если скриншот нужен — `scale: 0.5`, одна область через `zoom`.
6. **Субагенты** — только если пользователь просит: каждый стартует с нуля и заново читает контекст.
7. **Правки пачкой**: однотипную замену в многих файлах — одной командой/скриптом, а не десятком `Edit`.
8. **Ответы** — кратко: итог, ссылки `файл:строка`, без пересказа кода.
9. **Длинная сессия**: на смене этапа (исследование → реализация → проверка) — `/compact` с указанием, что сохранить; новая независимая задача — новая сессия.
10. **Модель/усилие**: рутину (переименования, мелкие правки) можно делать на меньшем уровне усилия; сложную архитектуру — на высоком.

## Разбор расхода
- Скилл `anthropic-skills:explain-usage` — график, на что ушли токены в текущей сессии.
- Типичные причины перерасхода и лечение:
  - прочитан `mock/*.ts` целиком → Grep + диапазон;
  - много скриншотов → текст страницы;
  - исследование без карты → дополнить `CLAUDE.md` (кратко, это загружается в каждую сессию — держать до ~60 строк);
  - повторные `build` ради проверки мелочи → `typecheck`.
