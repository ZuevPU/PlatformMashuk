# Цифровая экосистема Центра знаний «Машук»

Платформа сопровождения слушателей образовательных программ АНО «Центр знаний «Машук».
Не LMS: платформа не ведёт курсы, а сопровождает программу — от анонса и расписания
до материалов, общения участников и живой обратной связи.

## Что уже готово (волна 0–4)

- **Дизайн-система** на токенах фирменного стиля: палитра, сезонные схемы,
  типографика Geologica + Noto Serif (локально), mesh-свечения, горный хребет,
  стеклянные поверхности, пилюли-кнопки и теги.
- **Витрина программ** — каталог с фильтрами по статусу, направлению и сезону,
  поиском и разделом «Идут и готовятся к старту».
- **Страница программы** — hero с акцентом сезона, «О программе», результаты,
  расписание по дням с табами, материалы по блокам, блок итогов с авторским
  одностраничником и кодом доступа.
- **Архив программ** — прошедшие программы со ссылками на авторские лендинги.
- **Хаб программы** (`/programs/[slug]/hub`) — рабочее пространство участников:
  - канал: посты команды Центра и модераторов, комментарии, ответы на комментарий,
    реакции, закреплённые посты, вложения-фотографии, упоминания участников;
  - редактор постов (TipTap) с простым форматированием: жирный, курсив,
    подчёркнутый, зачёркнутый, списки, цитата, ссылка, упоминание, фотография;
  - раздел «Участники» с поиском и группировкой по ролям;
  - роли `admin` / `moderator` / `participant` с реальным разграничением прав
    и демонстрационным переключателем «Смотреть как»;
  - ссылка на раздел: `/programs/[slug]/hub?tab=members`.
- **Опросы и квизы** (`/programs/[slug]/hub?tab=polls`) — живая обратная связь:
  - типы вопросов: один вариант, несколько вариантов, открытый ответ (список или
    облако слов), шкала 1–5, вопрос квиза с очками и временем на ответ;
  - библиотека из восьми шаблонов под типовые ситуации программы плюс опрос с нуля;
  - конструктор: вопросы, варианты, верный ответ, время, очки, анонимность;
  - экран ведущего: код для участников, приём ответов, показ результатов,
    переход по вопросам, таймер и живой счётчик ответивших;
  - экран участника: ответ с телефона по коду, состояние «ответ принят»;
  - результаты: столбцы с процентами, облако слов, средний балл по шкале,
    список открытых ответов и лидерборд квиза;
  - выгрузка: таблица CSV для Excel (сводка по вопросам + все ответы) и картинка PNG
    с результатами текущего вопроса;
  - тёмная сторона демо: ответы других участников добавляются кнопкой
    «Сымитировать ответы» — на волне 5 их заменит настоящий реалтайм.
- **Чаты программы** (`/programs/[slug]/hub?tab=chats`) — общение участников:
  - группы по направлениям и командам плюс личные диалоги один на один;
  - список бесед с последним сообщением, временем и счётчиком непрочитанных;
  - поиск по беседам, создание группы с выбором состава, старт личного диалога
    из карточки участника;
  - лента сообщений с разделителями по дням, ответом на конкретное сообщение,
    реакциями, вложениями и тем же редактором, что и в канале;
  - свои сообщения выделены сезонным акцентом, чужие — как карточки с автором и ролью.
- **Страница входа** — как слушатель попадает в рабочее пространство программы.

## Запуск

Самый простой способ — двойной щёлчок по **`start.cmd`**: скрипт проверит Node.js,
при необходимости установит зависимости, поднимет сервер и откроет браузер.
Подробная инструкция по-русски — в [ЗАПУСК.md](ЗАПУСК.md).

Вручную:

```bash
npm install       # или pnpm install
npm run dev       # http://localhost:4321
npm run build     # production-сборка вместе с проверкой типов
npm run typecheck # только проверка типов
npm run smoke     # дымовая проверка в браузере (нужен запущенный сервер)
npm run shots     # пересобрать скриншоты в docs/screenshots
```

Порт **4321** зафиксирован в скриптах: на машине разработки порты 3000 и 3001
заняты другими проектами. Свой порт — `npm run dev -- -p 4400`.

Требуется Node.js 20+. База данных для запуска не нужна: платформа работает
на демонстрационных данных из `src/lib/mock/`.

`pnpm smoke` поднимает headless-браузер, подключается по Chrome DevTools Protocol
и проверяет реальные сценарии: гидратацию редактора, публикацию поста, реакции,
закрепление, переключение ролей, конструктор опросов, ответ участника,
имитацию ответов, чаты и выгрузку файлов. `pnpm shots` делает то же самое
для снимков экрана. Оба скрипта запускаются и через `node scripts/...`.

## Данные и база

Платформа умеет работать в двух режимах, интерфейс в них одинаковый:

| Режим | Когда включается | Что читает |
| --- | --- | --- |
| Демонстрационный | переменная `DATABASE_URL` не задана | `src/lib/mock/` |
| База данных | задана `DATABASE_URL` | PostgreSQL через Drizzle |

Схема — в [src/lib/db/schema.ts](src/lib/db/schema.ts) (19 таблиц: программы, дни,
блоки, материалы, участники, посты, комментарии, реакции, опросы, вопросы, сессии,
ответы, беседы, сообщения, отметки о прочтении, приглашения, сессии входа). Запросы —
в [src/lib/db/queries.ts](src/lib/db/queries.ts), они возвращают те же структуры,
что и демонстрационные модули.

### Вход по приглашению

Паролей нет. Три способа, все ведут к одной записи приглашения:

| Способ | Как работает |
| --- | --- |
| Персональная ссылка | `/invite/<токен>` — одноразовая, сразу открывает хаб программы |
| Код на почту | `/join` → код → сессия |
| Код в SMS | то же самое, провайдер подключается отдельно |

Приглашение принадлежит **человеку**, а не программе: один слушатель может
приехать на несколько программ, вход у него один. Роль в каждой программе
берётся из `program_members` и определяет права в интерфейсе. В браузере лежит
только непрозрачный токен сессии в httpOnly-cookie; в production cookie
отдаётся исключительно по HTTPS.

### Запись

Публикация постов, комментарии, реакции, закрепы, сообщения в чатах, создание
групп, **ответы на опросы**, **создание опросов и управление живой сессией**
(запуск, переход по вопросам, приём ответов, завершение) выполняются серверными
действиями в [actions.ts](src/app/programs/[slug]/hub/actions.ts). Права
проверяются по сессии и роли в программе, автор берётся из сессии — подписаться
чужим именем или опубликовать пост без прав нельзя. В анонимном опросе участник
не записывается вовсе: анонимность обеспечена тем, что связь с человеком не
хранится.

Интерфейс обновляется сразу, запись уходит в базу следом; если база вернула
отказ, в хабе появляется предупреждение с причиной.

Идентификаторы вопросов в базе содержат префикс опроса (`poll-…--k-1`), потому
что вопросы шаблонов общие для программ. В интерфейс они отдаются **как есть**,
без преобразований: так клиент возвращает ровно тот id, который есть в базе.

### Фотографии

Загрузка идёт через `POST /api/upload`; при подключённой базе требуется сессия.
Драйвер хранилища выбирается переменными окружения: пока их нет, файлы лежат
в `public/uploads/ГГГГ-ММ/` и раздаются приложением. Для боевого сервера
достаточно задать `S3_ENDPOINT` и `S3_BUCKET` — интерфейс `saveUpload`
в [storage.ts](src/lib/storage.ts) остаётся тем же, менять вызовы не придётся.

Ограничения: только изображения, до 8 МБ. Локальное превью показывается сразу,
затем адрес подменяется на постоянный.

Проверить запись целиком можно скриптом:

```bash
npm run check:writes -- http://127.0.0.1:4321 <токен-сессии>
```

Он выполняет сценарий в браузере (пост и сообщение) и печатает маркеры,
по которым видно результат в базе.

```bash
npm run db:migrate   # применить миграции
npm run db:seed      # перенести демонстрационные данные в базу
npm run db:generate  # сгенерировать миграцию после изменения схемы
```

Проверено, что при включённой базе интерфейс работает так же: `pnpm smoke`
проходит 29/29 и на демонстрационных данных, и на данных из PostgreSQL.

## Источники фирменного стиля

Все значения палитры, типографики и правила использования элементов взяты из
«Руководства по использованию фирменного стиля» АНО «Центр знаний «Машук» (41 стр.):

- основной синий `#223F9A`, тёмный сланец `#332D24`, чёрный `#0A1014`, серый `#DCDEDD`;
- сезонные схемы: весна `#3AD754` / `#0B4D4D`, лето `#FF5B00` / `#F18300`,
  осень `#F24559` / `#F68E9A`, зима `#4582F2` / `#D6E3FB`;
- Geologica — основной шрифт, Noto Serif — для больших текстов, Verdana — только фолбэк;
- **линейные цветовые градиенты не используются**: фон строится на радиальных
  mesh-свечениях, 1px-сетка применяется как паттерн.

## Данные

Программа «Образование на высоте» заполнена реальными данными авторского
одностраничника команды Центра. Остальные программы в `lib/mock/programs.ts`
помечены `demo: true` — это заполнитель для вёрстки. Слой `lib/data.ts` —
единственное место, которое меняется при переходе на PostgreSQL.

## Что заменяется при переходе на базу

Сейчас хаб и витрина работают на демонстрационных данных, но вся логика разграничения
прав, реакции, публикация и обсуждение уже настоящие — они выполняются на клиенте.
На волне 5 меняются только `lib/data.ts`, `lib/hub.ts` и добавляются серверные
действия: компоненты интерфейса остаются без изменений.
