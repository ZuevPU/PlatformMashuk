# Платформа «Машук»

Цифровая платформа сопровождения слушателей образовательных программ
АНО «Центр знаний «Машук». Не LMS: не ведёт курсы, а сопровождает программу —
от анонса и расписания до материалов, общения участников и живой обратной связи.

## Что делает

- **Каталог программ** и страница программы (описание, расписание).
- **Рабочее пространство программы** для участников: канал с постами и
  комментариями, чаты, расписание, материалы, участники.
- **Живые опросы и квизы**: облако слов, варианты, шкала, ранжирование,
  Q&A с голосованием и модерацией, колесо, командный и обычный квиз, режим
  презентации с QR-кодом и входом по ссылке.
- **Админка**: программы, расписание, материалы, состав и пароли.
- **Личный кабинет** участника.
- **Вход без паролей-регистраций**: по паролю программы и личному паролю.

## Технически (кратко)

- **Next.js 16** (App Router) + **React 19**, **TypeScript**, **Tailwind 4**.
- **PostgreSQL** через **Drizzle ORM**; без базы работает демонстрационный режим.
- **Реалтайм** — Server-Sent Events; редактор текста — **TipTap**.
- **Файлы** — локальное хранилище или S3-совместимое.
- **Ошибки** — Sentry-совместимый приём (GlitchTip).
- **Деплой** — Docker Compose (приложение + PostgreSQL + Caddy с HTTPS).
  Образы собираются в GitHub Actions и публикуются в `ghcr.io`, сервер
  обновляется автоматически; резервные копии — по cron.

## Запуск

```bash
npm install
npm run dev     # http://localhost:4321
```

Для запуска база не нужна — платформа работает на демонстрационных данных.
