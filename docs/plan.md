# План разработки

## Готово
- **Основа**: Next.js 16 (App Router), React 19, TypeScript, Tailwind 4; PostgreSQL + Drizzle; демо-режим без базы.
- **Публичная часть**: каталог «Наши программы» с живым поиском и фильтрами, страница программы (описание + вход).
- **Кабинет участника** (`/programs/<slug>/hub`): канал, чаты, расписание (таблицей, экспорт `.ics`), материалы, участники — на телефоне нижнее меню.
- **Опросы и квизы**: варианты, несколько вариантов, облако слов, список, шкала, ранжирование, Q&A с голосованием и модерацией, колесо, квиз, командный зачёт; режим презентации с QR и ссылкой; авто-закрытие по таймеру; один активный опрос на программу; удаление опросов; выгрузка CSV и PNG.
- **Вход**: пароль программы + личный пароль, роли (админ Центра, модератор, участник), защита от перебора; личный кабинет (профиль, смена пароля, удаление аккаунта, выход).
- **Админка**: программы, расписание, материалы, доступ и участники, сборка; счётчики постов/комментариев/участников; удаление постов и сообщений.
- **Инфраструктура**: Docker Compose (приложение + PostgreSQL + Caddy с HTTPS), образы в `ghcr.io`, автообновление сервера, бэкапы по cron, GlitchTip (Sentry), `robots.txt`, `sitemap.xml`, PWA-манифест.

## Дальше
1. **Self-paced режим** опросов (прохождение в своём темпе, без ведущего).
2. **Ручной состав команд** в командном квизе (названия, цвета, drag участников).
3. **Вложения-файлы** в канале (не только изображения) и редактирование постов.
4. **Чаты**: поиск по сообщениям, закреплённые беседы.
5. **Восстановление пароля** по email (SMTP) или SMS.
6. **S3-хранилище** для фото и сборок (драйвер в коде готов, нужны ключи).
7. **Масштабирование**: Redis pub/sub вместо шины в памяти, если понадобится более одного инстанса.
8. **PWA**: офлайн-режим и установка на экран.
9. **Аудит безопасности** и нагрузочное тестирование перед крупным мероприятием.

## Принципы
- Минимум лишнего в интерфейсе: у участника — то, что нужно сейчас.
- Все права проверяются на сервере, автор записи берётся из сессии.
- Цвета/шрифты/радиусы — только через токены фирменного стиля.
